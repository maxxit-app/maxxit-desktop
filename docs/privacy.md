# Privacy and data

A Maxxit account is required before using the desktop, including free analytics. Browser approval links this Mac to a verified account. Each account has an encrypted local database; the key and device credential are separate Mac Keychain items. Local features remain available for seven days after the most recent successful verification while offline. Sign-out and known revocation lock access.

Web sharing is optional and separate from hosted AI. Scope choices cover allowance history and token analytics, project names and descriptions, shared preferences, and detailed workflow prompts/results. Shared detail is stored by the backend and displayed to the same account on the web. Local SQLCipher encryption does not provide end-to-end encryption for that mirror. Review prompts and reports for sensitive content before enabling workflow sharing. See [the local workflow contract](local-workflow.md).

Provider passwords, provider authentication files, raw sessions, and browser cookies are never collected for sync. Shared preferences exclude native paths. Workflow bundles can include text you supplied, including paths or pasted context, when detailed sharing is enabled. Codex account identifiers are
hashed locally for grouping; hashes and derived labels are not anonymization guarantees.
The source JSONL files may contain conversations even though only usage fields are kept.

Mac Keychain protects the device credential. Native file dialogs require user
selection; autostart is optional. The Claude bridge can execute the pre-existing
status-line command solely to preserve its output after the user approves installation.

CSV export contains observed daily token totals and unknown dates as blanks.
Local uninstall and optional data removal are explained in install-macos.md.
Hosted services have separate storage, backups, and account deletion rules.

Local prompts, suggestions, and task reports expire after 90 days. Explicit prompt/result exports and clipboard copies are plaintext and user-controlled. Optional completion events contain random IDs, fixed status, and timestamps only. Server event records and their generic notifications expire after seven days. Completion relay requires browser-approved device consent and Pro. Native notices contain no project content; if macOS blocks them, imported records remain visible in Ideas. Maxxit does not control retention or additional context loaded by your own Codex or Claude.
