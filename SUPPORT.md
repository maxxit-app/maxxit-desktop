# Support

Use GitHub issues for reproducible desktop bugs and feature requests. Search
existing reports first and include the desktop/macOS versions, Mac architecture,
installation channel, and affected provider.

Email contact@maxxit.app for account, subscription, email delivery, or personal
data requests. Do not put billing details or identity documents in GitHub.
For security reports, use the private route in SECURITY.md.

Start with docs/install-macos.md and docs/providers.md for setup and known limits.
Follow docs/diagnostics.md for evidence you can safely attach.

Support is maintained on a best-effort basis. A response is not a promise of a fix
date. The maintainer reviews the public issue queue weekly when available.

For desktop errors, Settings > Diagnostic reporting shows delivery health and can send a synthetic test report. Include its event ID in a bug report. Preview the sanitized support JSON before exporting it. See [Sentry setup and limits](docs/sentry.md).
